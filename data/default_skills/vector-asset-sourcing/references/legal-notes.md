# Licence and trademark notes for printed products

You aren't giving legal advice. You are making sure the user can make an informed choice, so state the caveat
in one line and move on. Don't refuse ordinary label work over these points.

## Copyright licence (who drew the file)
| Licence | On a product? | What to do |
|---|---|---|
| CC0, Public domain, PDM | yes | nothing; keep the manifest |
| MIT, ISC, BSD, Apache-2.0, OFL | yes | keep the licence notice with the source files (manifest); nothing on the product |
| CC BY | yes, with credit | credit can't go on a label. Prefer an alternative, or credit on the website/catalogue and tell the user |
| CC BY-SA | risky | credit **and** the whole derived artwork under BY-SA. Avoid for client branding |
| NC (non-commercial), ND (no derivatives), "personal use", unknown | no | don't use (the script rejects these) |

## Trademarks and regulated marks (separate from copyright)
A file can be CC0 and still show a protected mark. Flag these:

- **GINETEX care symbols.** They are registered trademarks. In many countries (most of Europe, some others)
  using them on labels requires a licence from the national GINETEX committee. The ISO 3758 symbols are
  the same graphics. The Iconify `ginetex` drawings are MIT-licensed as files, but that doesn't grant the
  trademark. One line to the user is enough: "The care symbols are GINETEX/ISO 3758. Check whether your market
  requires a GINETEX licence."
- **EAC, CE, UKCA, and similar conformity marks.** Placing one states that the product is certified or compliant.
  Use them only when the user says the product is. Keep the official proportions (don't stretch, keep min height:
  EAC ≥ 5 mm, CE ≥ 5 mm).
- **Certification logos (OEKO-TEX, GOTS, FSC, Fairtrade, Woolmark …).** Only licence holders may print them, and
  usually with their own artwork and licence number. Don't fetch these from the web. Ask the user for the
  official file from their certificate.
- **Other companies' logos and brand names.** Never source someone else's brand artwork for a design. For the
  user's own or their client's brand, the client's file is the right source.
- **Commons `Restrictions` field** (`trademarked`, `insignia`, `personality`): pass it on to the user.
